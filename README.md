🏡 India Real Estate Price Analysis

An interactive Power BI dashboard for analyzing real estate property prices, areas, and property distribution across selected Indian cities.


📌 Project Overview

This project analyzes real estate listings using Microsoft Power BI. The dashboard provides insights into average property prices, price per square foot, property counts, and property distribution across cities.

🎯 Objectives

- Analyze average property prices across cities.
- Compare average price per square foot.
- Understand property distribution by city.
- Explore the relationship between property price and area.
- Use interactive filters to analyze selected cities and price ranges.


📊 Dashboard Features

- 📍 City-wise Analysis – Compare real estate indicators across cities.
- 💰 Average Property Price – View the average property price in lakhs.
- 📐 Average Area – Understand the average property area.
- 🏢 Total Properties – View the number of property listings.
- 📈 Price vs Area – Explore the relationship between property size and price.
- 🍩 Property Distribution – Visualize the share of properties by city.
- 🎛️ Interactive Slicers – Filter the dashboard by city and property price range.


🛠️ Tools Used

- Power BI Desktop – For data modeling and interactive dashboard creation.
- Power Query – For data transformation and cleaning.
- DAX – For creating measures and calculating key performance indicators.
- Microsoft Excel – For storing and preparing the dataset.


📁 Project Files
